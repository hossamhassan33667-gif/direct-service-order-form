# شركة دايركت سيرفس — نموذج طلب بضائع

تطبيق عربي لإعداد طلبات البضائع. يقرأ كتالوج الأصناف من Google Sheets، ويتيح البحث والتصفية وإدخال الكميات وبيانات العميل، ثم تصدير الطلب إلى Excel. يستورد الكتالوج تلقائيًا عند فتح الموقع ويحدّثه كل دقيقة.

## أعمدة كتالوج Google Sheets

ضع عناوين الأعمدة في الصف الأول بهذا الترتيب أو بأي ترتيب آخر:

`كود الصنف`، `اسم الصنف`، `الفئة`، `البراند`، `الوحدة`

أضف الأصناف أو احذفها أسفل العناوين؛ التغييرات تظهر في الموقع عند التحديث التالي. ملف الكتالوج الحالي: https://docs.google.com/spreadsheets/d/1i6UZ6MnatsXfHIny2jVIYF3WSKncvduXnLITVY3o0ZA/edit

## الربط المنشور

تم إعداد تطبيق Google Apps Script مرتبط بالشيت ونشره كواجهة قراءة للكتالوج. رابط الواجهة محفوظ في `SHEETS_CATALOG_API_URL` داخل `src/App.jsx`. يعرض التطبيق الأصناف عند فتح الموقع ويحدّثها كل دقيقة، كما يمكن تحديثها يدويًا من زر **تحديث الأصناف**.

مصدر كود الواجهة المنشورة موجود في `google-apps-script/Code.gs`. عند تعديل هذا الكود مستقبلًا، انشر إصدارًا جديدًا من مشروع Apps Script حتى تظهر التغييرات على الموقع.

الموقع يعرض بيانات الأصناف لزواره؛ لذلك يستطيع أي زائر للموقع قراءة حقول الكتالوج من واجهة القراءة. يمكن إبقاء ملف الشيت نفسه خاصًا. لا يكتب الموقع إلى الشيت.

## تشغيل الموقع

1. ثبّت Node.js وnpm.
2. شغّل `npm install` داخل مجلد المشروع.
3. شغّل `npm run dev` لفتح نسخة التطوير.
4. لإنشاء نسخة إنتاجية شغّل `npm run build`.

يعتمد التنسيق على Tailwind CSS من CDN، وتستخدم المكتبة `xlsx` لاستيراد أو تصدير ملفات Excel. كتالوج الأصناف المحدد لا يتضمن عمود سعر؛ لذلك تكون الأسعار وإجماليات الطلب صفرًا ما لم تُستورد الأسعار من ملف Excel.
